# Henry Hub Natural Gas Weather & Intraday Trading Terminal ⚡📈

Профессиональный аналитический терминал для трейдинга фьючерсами на природный газ Henry Hub (тикеры NG в Т-Инвестициях / MOEX). 
Система агрегирует метеорологические модели высокого разрешения (GFS и ECMWF), фундаментальные данные EIA по хранилищам и добыче, номинации сырьевого газа на СПГ-терминалы США и рассчитывает взвешенный внутридневной сигнал движения цены с автоматическим логированием в Google Таблицы.

---

## 🌟 Ключевые возможности

1. **Котировки Т-Инвестиций (T-Bank Invest API):**
   - Ближайшие фьючерсные контракты на природный газ (NGV6, NGX6, NGZ6 и др.).
   - Стаканы, последние цены, шаг цены, время экспирации и дата обновления.

2. **Погодные модели GFS и ECMWF (Open-Meteo 0.25°):**
   - Расчёт температурных аномалий и градусо-дней отопления/охлаждения (HDD / CDD) для ключевых регионов потребления:
     - **Северо-восток США (Northeast):** Нью-Йорк, Бостон, Пенсильвания.
     - **Центральная часть США (Midwest / Central):** Чикаго, Иллинойс, Огайо.
   - Прогноз на 2–4 дня вперёд и сравнение расхождений между моделями GFS и ECMWF.

3. **Фундаментальные данные EIA (API v2):**
   - Запасы газа в ПХГ США (Underground Natural Gas Storage) в сравнении со средним 5-летним уровнем.
   - Недельные темпы отбора/закачки (Net Change).
   - Суточные и месячные уровни сухой добычи газа (Dry Gas Production).
   - Историческое наложение сезонного потребления прошлых лет (2023, 2024, 2025 vs норма).

4. **Экспорт СПГ (DOE / LNG Feedgas Nominations):**
   - Мониторинг ключевых экспортных терминалов: Sabine Pass, Freeport LNG, Corpus Christi, Cameron LNG, Calcasieu Pass, Elba Island, Cove Point.
   - Суммарный поток feedgas в Bcf/d и суточные отклонения.

5. **Внутридневной прогноз (Intraday Forecast Engine):**
   - Взвешенный композитный скоринг (-100 до +100):
     - Погода (35%)
     - Запасы EIA (25%)
     - Добыча EIA (15%)
     - Экспорт СПГ (15%)
     - Текущий ценовой импульс (10%)
   - Определение сигнала (БЫЧИЙ / МЕДВЕЖИЙ / НЕЙТРАЛЬНЫЙ), целевой цены и диапазона волатильности.
   - Интерактивный симулятор сценариев (сдвиг температуры, потоков СПГ и дефицита/профицита запасов).

6. **Интеграция с Google Таблицами (Google Sheets v4 API):**
   - Автоматическая фиксация часовых прогнозов.
   - Верификация фактического исхода цены через 1 час с расчётом процента успешных прогнозов (Win Rate).

## 🚀 Быстрый старт локально

### Требования
- Node.js 20+
- npm или bun

### 1. Клонирование и установка зависимостей
```bash
git clone https://github.com/ВАШ_АККАУНТ/henry-hub-gas-terminal.git
cd henry-hub-gas-terminal
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Сервер запустится на [http://localhost:3000](http://localhost:3000).

---

## 🛠️ Сборка и запуск в Production

```bash
# Сборка статических файлов фронтенда
npm run build

# Запуск сервера
NODE_ENV=production npm start
```

---

## 🐳 Запуск через Docker

```bash
# Сборка образа
docker build -t gas-terminal .

# Запуск контейнера
docker run -p 3000:3000 gas-terminal
```

## 🔑 Переменные окружения (.env)

| Переменная | Описание |
|---|---|
| `PORT` | Порт сервера (по умолчанию `3000`) |
| `NODE_ENV` | Режим работы (`development` / `production`) |
| `TINKOFF_TOKEN` | Токен T-Bank Invest API для чтения котировок MOEX |
| `EIA_API_KEY` | Ключ доступа к API Управления энергетической информации США (EIA) |
